СТРУКТУРА ПАПОК:
\game\csgo\cfg\
 ├── autoexec.cfg       <- Головний тригер (у колірній папці cfg)
 └── PSuite\            <- Окрема створена папка для модулів
      ├── PSuite.cfg
      ├── PSuite_FPS.cfg
      ├── PSuite_INPUT.cfg
      └── PSuite_AIM.cfg

ОПИС МОДУЛІВ:
• autoexec.cfg   - Автоматично перенаправляє рушій в підпапку на запуск PSuite.cfg.
• PSuite.cfg     - Координує послідовність завантаження та фіксує параметри в системі.
• PSuite_FPS.cfg - Максимізує 1% і 0.1% Low FPS, вимикає зайві Panorama-процеси.
• PSuite_INPUT.cfg - Налаштування інпут-лагу через систему низької затримки сну Source 2.
• PSuite_AIM.cfg - Повний бойовий набір біндів, положення рук та 8 циклічних зелених прицілів.
