Ты — опытный C# архитектор софта и эксперт по низкоуровневой автоматизации в Windows. Наша цель — спроектировать три независимых метода детекта попаданий и хедшотов для легитного игрового ассистента RustVision под игру Rust. 

Код должен быть написан на чистом C# (для .NET 8 / .NET Framework 4.8), быть максимально оптимизированным, работать асинхронно, с минимальным инпут-лагом и без прямого вмешательства в память игры RustClient.exe (полный External без чтения RAM, чтобы не забанил EAC).

Пожалуйста, спроектируй и напиши архитектуру из трех функций (методов детекта):

1. Функция `aim1()` — Метод текстового комбат-лога через прицел (С фоновым чтением файла).
Логика: При запуске игры через аргументы передается `-logfile "C:\RustLogs\console_live.txt" +input.bind mouse2 "+aim;combatlog"`. 
Задача функции на C#: в фоновом режиме, используя FileStream с флагами FileMode.Open, FileAccess.Read, FileShare.ReadWrite, непрерывно читать конец этого файла без блокировки. Как только пользователь зажимает/отпускает ПКМ (Mouse2), игра невидимо для экрана пишет combatlog в файл. Функция должна мгновенно спарсить строки, найти маркеры "you", "head" или урон, вычислить изменение здоровья цели (old_hp / new_hp) и вернуть результат.

2. Функция `aim2()` — Метод аудио-захвата хедшота (Сниффинг системного звука).
Логика: Самый быстрый обход задержки сервера без банов. Когда в игре происходит хедшот, RustClient миттєво воспроизводит уникальный звук хруста ("crunch").
Задача функции на C#: использовать библиотеку NAudio (или WASAPI) для захвата аудио-потока из конкретного процесса RustClient.exe или системного микшера. Напиши базовый алгоритм или фильтр частот (анализ аудио-амплитуды / пиков), который детектирует этот специфический резкий всплеск звука хедшота в реальном времени и мгновенно возвращает событие true (Хедшот засчитан).

3. Функция `aim3()` — Метод визуального анализа хитмаркера (Pixel-Perfect OCR/Color Scanner).
Логика: При попадании в цель по центру экрана на долю секунды загорается маркер попадания (белый или красный хрестик хитмаркера).
Задача функции на C#: реализовать сверхбыстрый захват небольшого региона пикселей (например, квадрат 40х40 точно в центре экрана) через Win32 API (GetDC, BitBlt, без использования тяжелого и медленного Bitmap.GetPixel). Функция должна сканировать пиксели на наличие появления цвета хитмаркера (красный/красно-бордовый при хедшоте) и мгновенно триггерить попадание со 100% точностью.

Дополнительные требования к коду:
- Код должен быть монолитным, чистым и хорошо задокументированным на русском или украинском языке.
- Все три метода должны вызываться асинхронно (Task.Run), чтобы не фризить основной поток оверлея программы RustVision.
- Используй только официальные системные библиотеки Windows API (через DllImport) и стандартные стримы, минимизируя задержки (input lag).
