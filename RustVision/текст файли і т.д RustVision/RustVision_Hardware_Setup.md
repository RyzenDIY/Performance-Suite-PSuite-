# ТЕХНИЧЕСКОЕ ЗАДАНИЕ: АППАРАТНАЯ ШИ-СИСТЕМА (RustVision)

## 1. АРХИТЕКТУРА СИСТЕМИ (ДВОПКОВА СХЕМА)
Система розділена на два незалежних контури для забезпечення 100% невидимості (Undetectable) для ігрових античитів (Faceit, Vanguard, EAC):

1. **Ігровий ПК (Main PC):**
   * **Поточний конфіг:** Intel Core i7-2600 / GTX 960 (планується апгрейд на Ryzen 5 5600 / RX 6700 XT).
   * **Роль:** Запуск гри (Rust / CS2) у максимально можливій герцовці. На ПК повністю відсутній сторонній софт чи модифікації пам'яті гри.
2. **Другий ПК (Target PC):**
   * **Роль:** Обробка кадрів нейромережею YOLO в реальному часі та надсилання команд керування. Вся обчислювальна напруга ШІ лягає на це залізо.

---

## 2. ВИМОГИ ДО КАРТИ ЗАХОПЛЕННЯ (CAPTURE CARD)
Карта виступає апаратним дубликатором відеосигналу з нульовим навантаженням на центральний процесор (CPU) і відеокарту (GPU) ігрового ПК.

### Обов'язкові технічні критерії:
* **Інтерфейс:** Тільки USB 3.0 / USB 3.1 (перевіряти синій пластик у роз'ємі). Категорично уникати USB 2.0.
* **Чіпсет (для бюджетних нонеймів):** Тільки MacroSilicon MS2130 (забезпечує передачу сирого відео YUY2 без артефактів стиснення MJPEG).
* **Функція Passthrough (Loop OUT):** Наявність двох HDMI портів (Вхід від відеокарти -> Вихід на ігровий монітор) для забезпечення 0 ms затримки для очей гравця.
* **Герцовка:** Підтримка наскрізного сигналу (Passthrough) відповідно до монітора (60Hz / 144Hz / 240Hz).

### Рекомендовані моделі:
* Бюджетний варіант: Китайські "флешки" на чіпі MS2130 (чесні 1080p @ 60 FPS, низький інпут-лаг 20–40 мс).
* Оптимальний геймерський: EVGA XR1 Lite, AverMedia Live Gamer Mini (GC311) або Ezcap 321B.

---

## 3. МОДУЛЬ ЕМУЛЯЦІЇ МИШІ (INPUT CONTROLLER)
Для уникнення програмного перехоплення рухів миші античитом, доведення прицілу реалізується на апаратному рівні.

* **Залізо:** Плата Arduino Leonardo (або Pro Micro) на базі мікроконтролера ATmega32u4.
* **Принцип роботи:** Комп'ютер розпізнає плату як стандартну фізичну HID-мишу (наприклад, Logitech/Razer). Команди від ШІ передаються по COM-порту на Arduino, яка генерує "чисті" зміщення курсора в пікселях.

---

## 4. АЛГОРИТМ ТА ЛОГІКА РОБОТИ ШІ

```
[ Ігровий ПК (Гра) ] ──(HDMI)──> [ Карта захоплення ] ──(HDMI Passthrough)──> [ Ігровий монітор ]
                                         │
                                   (USB 3.0, YUY2)
                                         │
                                         ▼
                               [ Другий ПК (ШІ YOLO) ]
                                         │
                                  (Аналіз кадрів)
                                         │
                                         ▼
                               [ Плата Arduino ] ──(USB як HID-миша)──> [ Ігровий ПК ]
```

1. **Захоплення потоку:** Карта копіює відеосигнал з ігрового ПК і через USB 3.0 передає неспресований потік кадрів на Другий ПК.
2. **Обробка нейромережею:** Скрипт на Python (використовуючи YOLOv8 / YOLOv10) аналізує кожен кадр, шукаючи навчені класи об'єктів (голови, моделі гравців, елементи екіпірування).
3. **Обчислення дельти:** Знаходяться координати центру цілі (Xt, Yt) відносно центру екрана (Xc, Yc). Обчислюється крок зміщення прицілу.
4. **Постріл/Доведення:** Команда передається на Arduino, яка миттєво рухає приціл в ігровому ПК.

---

## 5. КРИТИЧНІ ОБМЕЖЕННЯ ТЕХНОЛОГІЇ
* **Суто Aim-функціонал:** Оскільки система аналізує лише сухе зображення з монітора, вона НЕ може реалізувати ESP (ВХ крізь стіни), показ здоров'я чи радар за межами видимості. ШІ бачить лише те, що фізично бачить сам гравець на екрані.
* **Залежність від освітлення:** Якість розпізнавання цілей у Rust прямо залежить від видимості (ніч, туман, кущі та тіні погіршують роботу YOLO).
