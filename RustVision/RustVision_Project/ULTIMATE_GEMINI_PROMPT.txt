=========================================
ПРОМТ ДЛЯ ШІ (ІНСТРУКЦІЯ РОЗРОБНИКА):
=========================================
Ти — експерт із низькорівневого програмування мікроконтролерів (C++, Raspberry Pi Pico SDK) та обходу античітів (EAC/Vanguard). Нам потрібно написати прошивку для двоплатного апаратного сплітера миші (Dual-Pico RP2040 Setup) під софт RustVision.

ЗАДАЧА ДЛЯ ШІ:
1. Згенеруй код для Pico №1 (Master):
   - Отримання координат X, Y через Serial1 (від USB-to-TTL).
   - Читання тактових кнопок (GP14 — Panic Button, GP15 — Mode Switch).
   - Робота з OLED-екраном (I2C, SSD1306) — виведення режимів "Legit" або "Active".
   - Передача фінальних зміщень на Pico №2 через UART0 (GP0/GP1).

2. Згенеруй код для Pico №2 (Slave/Mouse Emulator):
   - Налаштування USB Host через блоки PIO на пінах GP2/GP3 для читання реальної миші на частоті 1000 Гц.
   - Отримання читерських координат від Pico №1 через UART.
   - Математичне додавання рухів (компресія інпуту).
   - Емуляція миші через рідний USB-порт. Напиши дескриптор для повного USB-спуфінгу (заміна VID/PID та серійника під Logitech). Повністю вимкни ініціалізацію віртуального COM-порту на цій платі.

Працюй у режимі zero-latency (оптимізація буферів, робота без затримок delay). Очікую покроковий код для обох плат.
