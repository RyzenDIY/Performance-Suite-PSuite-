# RustVision: Logic Module
Логіка ізольованого режиму роботи.
* Передача даних: Виключно через фізичний USB-to-TTL конвертер (чип CH340), що визначається як звичайний периферійний COM-порт.
* Жодного втручання в системні HID-драйвери ігрового комп'ютера.
* Апаратний Killswitch: При натисканні Panic-кнопки на PicoDeck передача даних миттєво обривається на апаратному рівні (розрив лінії UART).
